# **Ciencia de datos con Python para la toma de decisiones**

## **Introducción**

¡Bienvenido al módulo de **Ciencia de Datos con python para la toma de decisiones**! Este espacio ha sido diseñado para guiarte en un viaje estructurado: desde los primeros pasos en la configuración de entornos eficientes hasta el despliegue de modelos predictivos y tableros interactivos automatizados. 

En el modulo I, haremos el establecimiento de la arquitectura del entorno de desarrollo profesional mediante el aprovisionamiento de Jupyter Notebooks integrados en VS Code. El núcleo del módulo aborda las estructuras primitivas y estructuras de datos nativas del lenguaje para la transición hacia el diseño de pipelines de ETL con Pandas. Se profundizará en la ingesta de fuentes de datos semiestructuradas y planas (Excel, CSV), la vectorización de operaciones y las técnicas formales de limpieza, transformación de DataFrames e imputación avanzada de valores faltantes (NaN) para garantizar la consistencia analítica.

En el modulo II, haremos identificación de propiedades estadísticas subyacentes en conjuntos de datos utilizando Pandas. Aplicación de la estadística descriptiva para la caracterización empírica de variables a través del estudio de sus funciones de distribución y medidas de tendencia central y dispersión (media, mediana, varianza y sesgo). Implementación de análisis univariados y bivariados no paramétricos para la detección sistemática de outliers (valores atípicos) y el descubrimiento de correlaciones iniciales entre variables de negocio.

En el modulo III, haremos el estudio teórico y aplicación práctica de los principios de comunicación visual efectiva. Desarrollo de representaciones gráficas fundamentales de baja abstracción con Matplotlib y transiciones hacia el diseño de gráficos multivariados complejos con Seaborn. Generación de mapas de calor y matrices de correlación condicional para la evaluación visual de colinealidad, análisis de series de tiempo para tendencias temporales y la abstracción de métricas corporativas en gráficos comparativos optimizados para la toma de decisiones de nivel C-Suite (gerencial).

En el modulo IV, trabajaremos la formulación de arquitecturas predictivas supervisadas utilizando el ecosistema de Scikit-Learn. Tras fundamentar los casos de uso y la separación de conjuntos de entrenamiento y prueba, se implementarán fases de ingeniería de características y preprocesamiento avanzado (escalamiento, codificación de variables categóricas y reducción de dimensionalidad). Desarrollo e implementación guiada de:

- Modelos de Regresión: Optimización y estimación de variables continuas mediante Regresión Lineal con regularización (Lasso y Ridge), Support Vector Machines (SVM), XGBoost y Random Forest Regressor.

- Modelos de Clasificación: Discriminación y categorización probabilística mediante Regresión Logística, K-Nearest Neighbors (KNN), clasificadores Ridge, SVM, XGBoost y Random Forest Classifier.

Evaluación del sesgo y la varianza mediante protocolos estrictos de validación cruzada (Cross-Validation) y matrices de confusión (Precisión, Recall, F1-Score y curvas ROC).

Y por ultimo en el modulo V, producción, despliegue y encapsulamiento de soluciones analíticas. Introducción a la contenedorización de aplicaciones con Docker para garantizar entornos aislados y portables. Programación de interfaces web dinámicas mediante la arquitectura reactiva de Dash, dominando componentes del árbol DOM, layouts, y la lógica dirigida por eventos a través de callbacks iterativos e interactividad asíncrona concluyendo con estrategias de optimización para la puesta en producción y presentación ejecutiva de proyectos de datos.
